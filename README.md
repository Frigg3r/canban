# Kanban Board

Веб-приложение для управления задачами и организации командной работы в формате канбан-доски.

Проект появился как развитие внутренней информационной системы, которую наша команда разрабатывала под процессы подразделения. Готовые инструменты не полностью соответствовали требованиям и особенностям работы команды, поэтому было принято решение реализовать собственную систему.

Данная версия предназначена для локального запуска и демонстрации основных возможностей проекта.

## Основные возможности

- создание и редактирование задач;
- распределение задач между участниками;
- работа с командами;
- разграничение прав доступа;
- изменение статусов задач на канбан-доске;
- комментарии к задачам;
- рейтинг участников;
- статистика выполнения задач.

## Мой вклад

В рамках проекта я занимался:

- описанием предметной области;
- проектированием структуры базы данных PostgreSQL;
- реализацией разграничения прав доступа;
- разработкой серверной логики для автоматизации учёта задач;
- развитием отдельных функций системы.

Проект разрабатывался командой, поэтому репозиторий также содержит компоненты, созданные другими участниками.

## Локальный запуск

### Backend

Для подключения к PostgreSQL необходимо создать файл:

```text
server/config/db.php
```

на основе файла:

```text
server/config/db.example.php
```

и указать в нём параметры подключения к локальной базе данных.

Запуск серверной части из корня проекта:

```bash
php -S localhost:8000 -t server
```

### Frontend

```bash
cd client
npm install
npm run dev
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:5173
```
